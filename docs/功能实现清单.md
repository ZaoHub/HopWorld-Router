# 功能实现清单

## 已实现

- **本机代理发现和接入**：通过管理页按常用端口或指定端口扫描服务所在网络空间的回环地址，验证免认证 HTTP CONNECT / SOCKS5 代理；选择后通过固定的 VLESS Reality 本地节点使用该代理作为出口。
- **本地节点流量监控**：显示通过本地节点的上下行速度和当前 Xray 进程的累计流量；客户端直连其他订阅节点或使用 IKEv2 的流量不计入，Xray 重启后计数清零。
- **固定入口自动换线**：在本地节点选择上游自动模式，使用已启用且可解析的上游节点，由 Xray 基于所选目标的探测结果为新连接选择出口；无可用候选时阻断，不回退直连。支持选择探测目标和间隔，节点列表更新时重建候选配置，管理页可查看各候选最近的探测状态和延迟。
- **部署准备**：提供 Linux、Docker、Docker Desktop、macOS 用户后台服务、Windows 原生订阅管理 / WSL 2，以及实验性 OpenWrt 的安装或试用材料。
- **管理页安装缺少的系统组件**：Linux systemd 安装上以 root 执行一次 `deploy/hopworld-install-root.sh` 后，管理页可安装缺少的 Xray、sing-box、nginx、certbot 或 strongSwan，并在本机防火墙已经启用时放行对应端口。启用本地节点时安装 sing-box。不修改云安全组，不新开防火墙，也不自动配置订阅用的 443 站点。容器、macOS、Windows、WSL 用户进程和 OpenWrt 不适用，见各自试用指南。

## 未完整实现

- **自动换线**：未显示每条连接实际使用的出口；不支持多目标优先级，也不保证不中断已有连接。候选限于已启用且当前转换器支持的节点，节点越多，并发探测的资源和流量开销越大。观测通道不可用时无法显示状态，但不改变自动换线规则。
- **本机代理发现**：不支持带认证的本地代理、非回环地址、禁止访问本机地址的代理或跨容器网络空间发现。发现后需要用户选择，服务本身没有被修改或对外开放。
- **运行环境**：Windows 原生本地节点进程管理尚未适配；OpenWrt 尚无安装包。绿联、飞牛、Docker Desktop、WSL 和其他设备的部署与恢复尚未实机验证。
- **透明网关**：尚未实现自动接管局域网流量、DNS、IPv6 和防火墙规则，不能将已有试用配置当作透明网关。

## 验证状态

本地自动化测试和模拟代理验证不等于真实上游、真实 NAS、路由器、Windows 或 Docker 的实机测试。目标系统、版本、架构、功能、重启恢复和失败条件应按[运行环境适配路线图](运行环境适配路线图.md)逐一记录。
