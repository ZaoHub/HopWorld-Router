    • 与 IKEv2 系统 VPN 可同时使用，互不影响

    每次打开管理页都会提醒，直至本地网络节点已启用。

    iPhone 连接设置

    蜂窝推荐描述文件；也可手动添加 VPN

    请先在侧栏点「配置」启用 IKEv2，再安装描述文件。

    描述文件（推荐）

    在手机 Safari 打开安装链接，或在本机下载后 AirDrop 到手机。

    安装：打开链接或下载 → 设置 → 已下载描述文件 → 安装 → VPN 里连接 HopWorld。

    手动填写 VPN

    iPhone：设置 → VPN → 添加配置 → 类型 IKEv2

    • 服务器：—
    • 远程 ID：—
    • 本地 ID：留空
    • 用户认证：无
    • 描述：自定（如 HopWorld）
    • 共享密钥：—
    • 无法上网：断开 VPN 重连；Safari 试打开 http://1.1.1.1 区分 DNS/线路问题

    改 Remote ID 或密钥后需重装描述文件，或同步手动 VPN 字段。
